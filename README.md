# AskMedily

Plain English medication information for patients, carers, nurses and students.

## Features
- 💊 Drug search with plain English explanations
- 📊 Side effects ranked by frequency
- 🤖 AI Condition Agent — guides users from diagnosis to medication info
- 💳 Subscription tiers (Basic £4.99/mo, Premium £9.99/mo)
- 2-day free trial

## Tech Stack
- **Frontend**: Next.js 15, TypeScript, Tailwind CSS
- **Backend**: Next.js API Routes
- **Database**: Supabase
- **AI**: Anthropic Claude API
- **Payments**: Stripe
- **Deployment**: Vercel

## Environment Variables
Copy `.env.example` to `.env.local` and fill in your keys.

## Getting Started
```bash
npm install
npm run dev
```
